# Horror Aspatal

Developed with Unreal Engine 5
🕯️ Horror Escape Room – Unreal Engine 5 Game

Horror Escape Room is a short first-person horror experience built in Unreal Engine 5.
Your objective is simple — survive long enough to find the hidden sword and kill the ghost stalking you through the mansion.

This project focuses on atmosphere, AI behavior, level design, and Blueprint programming, showcasing the foundations of survival horror gameplay.

🎮 Gameplay Overview

Explore a dark, abandoned mansion with only a flashlight.

Search rooms, solve simple clues, and avoid the roaming ghost.

Find the ancient sword hidden somewhere in the level.

Confront the ghost and defeat it to escape.

If the ghost catches you unarmed… game over.

👻 Core Features
✔️ Enemy AI System

AI Perception (Sight) to detect the player

Patrol, chase, and attack behavior (Behavior Tree)

Attack system using sphere traces for precise melee hits

Death logic synced with game win condition

✔️ Player Systems

First-person movement

Pickup and interaction system

Flashlight system

Crouch and stealth movement

Sword pickup & combat activation

✔️ Environment & Level Design

Escape-room style mansion layout

Locked doors, keys, and triggers

Horror-focused lighting using Lumen

Fog, post-processing, and ambience for atmosphere

✔️ UI & Game Flow

Fade-in and fade-out transitions

“You Died” / “You Won” screens

Clean game state management via GameMode

🧰 Tech Stack

Unreal Engine 5 (Blueprints)

AI Controller + Behavior Tree + Blackboard

Animation Blueprint for enemy attack states

Sphere Trace–based melee system

Optimized assets imported from Sketchfab / Fab

📦 What I Learned

Setting up AI Perception and Behavior Trees

Designing modular Blueprint systems

Optimizing large UE5 projects (Nanite, Lumen, VRAM limits)

Creating horror atmosphere with lighting and sound

Asset pipelines (FBX, retargeting, collisions, UI)

🚀 Future Improvements

More complex puzzles and interactions

Better ghost animations & jumpscare logic

Inventory system

Improved sound design and music

Multiple endings
